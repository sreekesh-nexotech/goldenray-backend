## Notes for later packages

* Outbox handlers are **at-least-once**: a lease can expire during a very slow handler and the row is claimed again.
  Keep handlers idempotent (the `delivered` list only prevents re-running handlers that *finished*).
* `drain_outbox_sync()` (the `drain_outbox` fixture) no longer retries a failed row in the same call; tests that
  exercise retries move the clock to `next_attempt_at` (`freezegun`).
* A new staff view must extend `BaseAPIView`/`BaseViewSet`; an exemption is a shared-code change in
  `core/checks.py` plus a DEVIATIONS entry.
* Public cached views: pass `ttl=` for Redis, and `max_age=` only to go *below* 60 s.
* Enqueue tasks through a private `_enqueue_…` helper scheduled with `transaction.on_commit(partial(helper, …))`.
